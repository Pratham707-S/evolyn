# Dashboard Feature (`features/dashboard`)

> **Assigned Engineer:** Pratham Kave (Frontend & UI Implementation)
> **Reviewer:** Pratham (Project Lead)

---

## 1. Feature Responsibility
- Main landing view for the Evolyn Brand Governance Platform.
- Visual 5-step judge evaluation workflow stepper with live status indicators.
- Overview metrics (Active Guidelines count, Submissions reviewed, Compliance average, Detected Conflicts count).
- Quick-action shortcuts ("Upload Guidelines", "Submit Copy", "Review Queue").

---

## 2. Dependencies
- `@evolyn/shared`: Types and status enums.
- `lucide-react`: Icon system.
- `tailwindcss`: Styling and layout.

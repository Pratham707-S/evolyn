# Git Workflow & Team Collaboration

> **Team Matrix Mechanics**

---

## 1. Branch Naming Standard
Always branch off `main`:
- `feat/guideline-knowledge-hub` — Mann
- `feat/backend-submissions` — Ayan
- `feat/backend-reviews` — Ayan & Pratham
- `feat/frontend-dashboard` — Pratham Kave
- `feat/frontend-guidelines` — Pratham Kave
- `feat/frontend-review-workbench` — Pratham Kave

---

## 2. Commit Message Standard
Follow Conventional Commits:
- `feat(module): add new capability`
- `fix(module): resolve edge case bug`
- `docs(module): update specification`
- `test(module): add unit test coverage`

---

## 3. Pull Request Requirements
1. Run `./scripts/verify.sh` locally.
2. Fill out every section of `.github/pull_request_template.md`.
3. Obtain sign-off from Pratham before merging into `main`.
